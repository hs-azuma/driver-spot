# 実装・実運用開始時の法的／運用確認事項

更新日：2026-10-13
運営予定：CSクリエーション株式会社
ユーザー指示：実装時の確認事項として残す。

## 現在の扱い
ホームページには勤務前の一般的な確認案内を掲載済み。案内の掲載は、許認可・保険・運行条件の確認完了を意味しない。
以下は未確認事項として管理する。過去の口頭相談や他社サービスの運用だけで適法性を確定しない。

## 優先確認
- [ ] 運輸支局：一般貨物の運転者選任に関する日雇い・2か月以内の期間雇用等の制限と、想定する雇用形態・車種での利用可否を確認する。
- [ ] 運輸支局：横乗り→指導→適性確認→ワンマンの運用、点呼・運転者台帳・健康確認・教育記録の必要事項を具体的な運用案で確認する。教育実施だけで選任制限が解消すると扱わない。
- [ ] 労働局：求人公開、希望条件による検索・通知、企業からの案内、応募・選考・採用、手数料の仕組みを提示し、職業紹介の許可／特定募集情報等提供事業の届出の要否を確認する。
- [ ] 契約：雇用主、労働契約成立の時点、労働条件通知書の交付・保存、勤務条件変更への同意を専門家と整理し、画面・通知・規約と一致させる。
- [ ] 給与：最低賃金、割増賃金、休憩、企業都合のキャンセル・早上がり・休業手当、交通費の扱いを整理する。「給与保証なし」を法令上の支払義務の免除と扱わない。
- [ ] 副業：本業／他の勤務先の労働時間・勤務予定・契約情報の申告項目、受入企業が確認する方法、更新時期と証跡を設計する。
- [ ] 運転業務：拘束時間・休息・疲労を確認する方法、勤務を受け入れられない場合の扱いを整理する。スポドラ内の重複応募防止だけで本業との時間管理が済むと扱わない。
- [ ] 保険：労災、臨時運転者への自動車保険の適用、対人・対物・貨物事故の補償と責任分担、事故時の連絡・申請を受入企業・保険会社と確認する。
- [ ] 個人情報：免許・連絡先・評価等の利用目的、企業への提供範囲と同意、保存期間、退会後の保存・削除、外部サービスへの委託を整理する。
- [ ] 公開文書：ドライバー／企業の利用規約、プライバシーポリシー、料金、問い合わせ窓口、運営会社情報を確定して掲載する。未確認の許可・補償・安全保証を表示しない。

## タイミーとの比較
職業紹介の許可等、雇用・キャンセル、本業との労働時間、労災、個人情報は共通する確認分野。
運転者選任、運行管理、拘束・休息、車両・貨物保険は運転業務として追加確認が必要。
他社の許可・補償・規約をそのままスポドラに適用しない。

## 確認結果の記録方法
各項目について「確認日／担当窓口／提示した運用／回答／必要な実装／完了証跡」を追記して管理する。
