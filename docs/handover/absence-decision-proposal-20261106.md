# 未確認勤務・欠勤・取消の確定方針

2026-11-06（日本時間）。F27完了。提示済みの案Aについて、所有者から「f27進めて」と指示を受け、運用方針・記録方法・今回の実装範囲を確定した。

## 採用する運用

既存の「出勤未確認」「勤務実績未確認（要確認）」「退勤未確認」を起点に、受入企業の勤務管理担当が本人と事実を確認する。
確認日時、確認者、理由、取消・訂正前後の内容を非公開台帳へ追記する。
現場で対応する担当者本人と代理者の氏名、窓口と運用開始日は、実案件の受入前に企業側が指定する。運用開始の判定はF30で管理する。

| 役割 | 担当する作業 |
|---|---|
| ドライバー本人 | 勤務有無、実際の出退勤・休憩、打刻できなかった事情を申告 |
| 受入企業の勤務管理担当・代理 | 本人の申告と企業側の記録を照合し、事実確認と理由・日時を記録 |
| 受入企業の給与担当 | 確認した事実と契約・労務上の確認結果に基づき、給与・交通費の扱いを判断 |
| 運営窓口 | 確認の不一致や未解決案件を受付し、確認担当と次回対応を記録 |

## 状態ごとの手順

| 起点 | 確認と対応 | 完了の記録 |
|---|---|---|
| 出勤の打刻なし | 勤務有無と端末・通信・QRの事情を確認。勤務があれば既存の勤怠修正・申請・企業承認へ進む | 勤務の事実、確認者、日時、理由、申請・承認先 |
| 出勤後に退勤なし | 終了時刻と休憩を本人・企業で照合し、既存の修正・申請・承認へ進む | 修正前後、根拠、確認者、承認結果 |
| 欠勤申告 | 本人と企業双方の認識、連絡時刻・理由を確認。判断が分かれる間は確認中として扱う | 欠勤と判断した事実・根拠・確認者・日時と支払判断の担当先 |
| 企業側の取消 | 取消時刻・理由、本人への連絡、既に勤務・契約があるかを確認 | 取消前の条件、取消後の扱い、連絡結果、給与担当への引継ぎ |
| 確定後の訂正 | 元の記録を参照して訂正を追記し、必要な勤怠再申請・月次・CSV・連絡の修正を確認 | 訂正対象ID、変更前後、理由、確認者・日時、反映先と結果 |

## 非公開台帳の記録項目

1案件1つの案件IDを付け、勤務ID・求人ID、受付日時、申告した側、確認担当・代理、確認日時、理由と根拠、本人への確認状況を記録する。
確認状況は「要確認→確認中→事実確認済み→対応完了」で管理し、確認継続の場合は次の対応と担当を追記する。
確認結果は「勤務あり／欠勤／企業取消／確認継続」等の事実確認結果として記録する。
取消・訂正には元の案件IDまたは訂正対象ID、変更前後、理由、実行者と日時を付け、元記録を参照できる形で追記する。
本人確認や連絡先等を含む実台帳は、承認済みの非公開保管先で管理する。

## 今回確定した実装・検証範囲

既存の要確認表示、本人の勤怠申請、企業の差戻し・承認、再申請、本人表示、月次・CSVと、上記の非公開確認台帳を利用する。
F27は、この運用・役割・記録と利用範囲の確定として完了する。
